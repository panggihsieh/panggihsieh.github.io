# School3D 公開網站發布

- 主網站：https://panggihsieh.github.io/school3d/
- 校樹碳排：https://panggihsieh.github.io/school3d/tree/

此儲存庫只保存可公開的靜態網站，檔案位於 `dist/school3d/`，推送 main 後由 GitHub Actions 發布 dist。原始開發儲存庫 school3d 維持私人，沒有將其歷史或開發資料複製至此。

植物資料為教育部校園樹木資訊平臺的 2026-10-28 快照（大南國小 127 株、46 種），位置與造型為示意。平台儲碳不等於每年吸碳；碳計算係數由填寫者提供。資料在各自瀏覽器內編輯，無雲端同步。

Three.js 0.180.0 採 MIT，授權見 `dist/school3d/vendor/THREE-LICENSE.txt`。原始植物資料權利屬資料提供者；未轉載平台照片。
